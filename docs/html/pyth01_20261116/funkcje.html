Module pyth01_20261116.funkcje

Funkcje: definiowanie, return, brak przeciążania, sposoby przekazywania parametrów (*args, **kwargs, parametry tylko-nazwane), zakresy zmiennych (LEGB), pułapka mutowalnej wartości domyślnej, domknięcia, funkcja jako argument (key=).

Notatki ze szkolenia. Definicje funkcji są na poziomie modułu (można je importować), zakomentowane wywołania przy każdej funkcji to materiał do odkomentowania na zajęciach, a kod wykonywany jest pod if __name__ == '__main__'.
